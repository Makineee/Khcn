# Robot Assembly Lab (server version)
1. Install Node.js 18+.
2. `npm install` then `npm start` (default port 3000; change with `PORT=8080 npm start`).
3. Open `http://<server>:<port>/` on the projector. Phones open the QR codes shown at the BATTLE lobby (/c.html?t=0 and /c.html?t=1).
If you host behind HTTPS, make sure your proxy forwards WebSocket upgrades.
Edit the question bank (QS array) at the top of public/index.html.
